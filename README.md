# Edition Bildungsmedien

## Design System 1.0

`assets/css/design-system.css` ist die gemeinsame Designgrundlage für Emergence Technology. Die Integration erfolgt schrittweise und ersetzt nicht das bestehende helle Design des Verlags und Shops.

### Verwendung

- Die Organisationsseiten verwenden das dunkle Emergence-Theme.
- Edition Bildungsmedien, Publikationsseiten und Shop behalten ihr helles Erscheinungsbild.
- Gemeinsame Komponenten umfassen Design-Tokens, Panels, Cards, Buttons, Badges, Fokuszustände und Reduced-Motion-Regeln.
- Künftige Consulting-, Forschungs- und Analyse-Seiten können mit der Klasse `emergence-theme` angeschlossen werden.

### Markenbereiche

- `edition-theme` – heller Verlag und Publikationen
- `consulting-theme` – Beratung und Governance
- `emergence-theme` – Dachmarke, Organisation, Forschung und Analyse
- Produkt-Tokens für PhoenixOffice, NanoCam und Leibnizmeter sind als Erweiterungspunkte vorgesehen.

Die Integration entfernt keine Shop-, Warenkorb- oder Publikationsinhalte.
